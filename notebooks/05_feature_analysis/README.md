# Feature Analysis and Table Generation

This directory contains notebooks used for generating extended feature-selection outputs and dissertation tables.

The notebooks in this directory were executed using Python 3.7.4 to export the complete feature-selection results used in the dissertation tables. The original experiments from the published paper were conducted using Python 3.6.3.

These notebooks are intended for analysis and reporting purposes only and do not affect the main experimental pipeline.

Generated outputs:
- TSV files in `../../results/tables/source/`
- LaTeX tables in `../../results/tables/latex/`

The generated LaTeX tables may contain minor manual formatting adjustments for dissertation integration and Overleaf compatibility.
